🛡️ 100% Stealth & Screen-Share Proof

Share your screen on Zoom, Microsoft Teams, or Google Meet with zero stress. Hardware-level DWM window protection guarantees your interviewer only sees your desktop—never the assistant window.

🎛️ Independent Mic & Speaker Source Control

Choose your exact input microphone and output playback device (headset, external monitor, or virtual cable) in Settings. Never miss audio due to Windows default audio switches.

👻 Click-Through Ghost Mode (Ctrl+Alt+C)

Make the overlay completely click-transparent. Code in your IDE, navigate tabs, and click on your video call directly through the assistant window without moving or minimizing it.

🧠 Resume & Job Description Synthesis

Upload PDF, DOCX, or TXT of your Resume, Target Job Description, and Notes. HackySack directly weaves your authentic career projects, tech stack, and measurable metrics into every response.

📸 1-Click Screen Capture OCR (F10)

Capture live LeetCode coding problems, SQL database schemas, or slide decks directly from your screen into structured text context with zero typing.

⚡ Teleprompter Live Response Format

Designed for 0.5-second glanceability during live calls. Features a 3-second direct answer, bold keyword pills, a 60-second speaking script, and copyable working code snippets—generated in under 1.5 seconds.

🎙️ Dual-Channel Speech Transcript Engine

High-performance Rust WASAPI audio capture simultaneously listening to system speaker loopback (interviewer) and microphone (candidate) with real-time speaker separation and VAD filtering.

🔒 Hardware-Encrypted Security & Free BYOK

Your API keys and tokens are encrypted with AES secret obfuscation in Windows Credential Manager. Supports 100% Free BYOK (Groq, OpenAI, Anthropic, Gemini, OpenRouter) or Zero-Setup Cloud Passes.

Quick Keyboard Controls

Shortcut Action Description
Ctrl + Shift + H Show / Focus Window Global hotkey to bring HackySack to front from anywhere in Windows
F8 Clear Context Buffer Instantly clears context buffer items and live transcript log
F9 Record / Stop Audio Starts or stops live background audio listening and transcription
F10 Capture Screenshot Captures active screen content as visual context for AI questions
F12 / F11 Ask AI Answer Triggers manual AI answer for the current transcribed question and history
Ctrl + Alt + C Click-Through Mode Passes mouse clicks directly through to windows behind HackySack
